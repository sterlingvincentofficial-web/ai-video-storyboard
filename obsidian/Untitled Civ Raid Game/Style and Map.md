# Style and Map
Back to [[00 Home]]

**To be designed in Claude Design.** Notes for that session:

## Avoiding slop (checklist)
- One art style, applied everywhere: same palette, same chunkiness, same outlines.
- No free-model grab bag; every model made or adjusted for this game.
- The plot **visibly changes per Age** (see [[Ages]]). This is the biggest thing separating us from slop.
- Feedback on everything: sounds, hit effects, coins flying, troops cheering.
- Custom UI that matches the theme (maps, banners, parchment), not default Roblox buttons.

## Map layout (keeps the familiar genre layout, our own look)
- **Player plots in a row**, with your army lined up at the front.
- **The world map** beyond the plots: zones, each a ruler's camp, at different distances. Farther away means harder and better loot.
- The routes between camps and plots are where the chase happens, so they need room to run and things in the way.
