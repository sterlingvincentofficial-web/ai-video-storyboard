## Decided
- [x] **What do we steal?** Eggs; units hatch from them with % odds. See [[Loot Ideas]].
- [x] **Do Ages reset anything?** No. Everything placed becomes level 1 of the next Age's version. Troops upgrade separately. Robux items are never replaced. See [[Ages]].
- [x] **Is the base or the battle the main part?** The base. Watching a raid is optional. See [[Civilization]].
- [x] **PvP?** Not for now. Parked, but kept in mind for later.
